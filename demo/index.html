What are Microarchitectural Weird Machines?

🔓

Traditional Computing

CPUs execute instructions that directly manipulate architectural state (registers, memory).

mov rax, 42    ; Store 42 in rax
add rax, 8     ; Add 8 to rax
; Result: rax = 50
⚡

µWM Computing

Exploit transient execution and microarchitectural side-effects (cache, RSB) to perform hidden computations.

div dl          ; Trigger exception
; ⚠️ Speculatively executes:
mov al, [rcx]   ; Cache side-effect
; Output encoded in cache state!

🔬 Why This Matters

µWMs enable:

  • Security Research: Understanding transient execution vulnerabilities (Spectre, Meltdown)
  • Side-Channel Analysis: Detecting covert channels in microarchitecture
  • Novel Computing: Exploring unconventional computation paradigms
  • Reverse Engineering: Observing hidden microarchitectural state transitions

🎯 MuWMEmulator

Core orchestrator that models transient execution, out-of-order effects, and coordinates all microarchitectural components.

💾 Cache Model

Simulates CPU cache behavior with LRU eviction policy and tracks cache hits/misses for side-channel analysis.

📚 RSB Model

Models the Return Stack Buffer used by FLEXO-based µWMs for encoding computation in return address predictions.

⏱️ Timer

Abstracts RDTSCP instruction for timing-based side channels and performance measurements.
